# Link

## Text

```code
(Link) -> link

text that goes somewhere, :link is where. Pressed, it emits, to
whatever it was connected to, and the action has its id, from which
the one who gets it finds the Link and reads where
```

### :draw

```code
(. link :draw) -> link
```

### :mouse_up

```code
(. link :mouse_up event) -> link
```
