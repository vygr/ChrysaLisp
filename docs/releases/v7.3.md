# ChrysaLisp 7.3

A draft, what has gone in since the 7.2 tag.

## Networks

*	A key for the links between machines. A machine with the file
	`mesh_key` links only to machines with the same one, each end proves it
	has it before the link carries anything. `link -k` makes a key. `sync`
	and everything else that goes over a link is behind it. With no key
	file nothing is changed. `docs/intro/intro.md`, "A Key".

*	`sync` sends the mode of a file, who may read, write and run it. A
	script arrives as one that can be run, and a file that is the same but
	for its mode has only that set. `docs/ai_digest/sync.md`.

*	New `rack`, a command line run on every machine of the mesh. Each is
	made the same as this one, then runs it in a session of its own, `rack
	"tests -a"`. `./rack.sh up` makes a machine a member. It is how the
	system is tested on three machines at once. `docs/ai_digest/rack.md`.

*	New `mesh` command, one command to join a machine to the others on a
	network, `mesh -j`, to make a key, `mesh -k`, and to say who is there
	and what to look at if nobody is. `docs/intro/mesh.md` is the guide.

*	A build has an id, the same on every CPU, and a machine says its own in
	its beacon. `mesh` names a machine that is on a different build.

## Apps

*	New Network Map, the network as it is, in three dimensions, laid out as
	a bedspring. A ball for each node, the color of its machine and the
	size of its load, a bar for each link, red when it is busy. Nodes come
	and go as they do. Under System in the launcher.

*	`(net-links)` gives the node, machine, load and bytes carried of each
	link, `lib/net/links.inc`. The kernel counts the bytes.

*	New `(Mesh-cylinder radius height eps)`.

*	Two new shaders, `shiny_vertex.shader` and `shiny_lit.shader`, a
	surface with a highlight. A scene object can be lit smooth, `:smooth`,
	and have a pair of shaders of its own, `:shaders`.

## Launch

*	The launch scripts for each shape of network, `run_ring`, `run_mesh`,
	`run_cube`, `run_star`, `run_tree` and their `run_tui_` and Windows
	twins, are gone. `run.sh` and `run_tui.sh` take `-t shape`, `./run.sh
	-t ring -n 8`. `docs/intro/intro.md`.

*	The first node makes the network, `(node-net shape cnt)`, the launch
	scripts start only it.

## The host

*	A new `snapshot.zip`, so `make install`, the host program has two new
	calls.

*	The `cpu`, `abi` and `os` files in the root of the tree are gone. The
	host program says what it is, `(pii-host)`, and `(cpu)`, `(abi)` and
	`(os)` ask it. A build removes the old files.

*	`(pii-chmod path mode)` sets the mode of a file.

## Shaders

*	The GLSL back end has a vertex stage. `(shader-glsl-pair vertex pixel)`
	gives the text of a vertex shader and a fragment shader that go
	together, as the Metal and SPIR-V back ends do. A GLSL compiler takes
	and links the pair of the Mesh demo, as GLSL ES 1.00 and as desktop GLSL
	1.20. No host draws with it yet.

## The hash and the cipher

*	New `lib/crypto/sha512.inc`, SHA-512, native, 488MB a second on an M4.

*	New `lib/crypto/ed25519.inc`, Ed25519, the signature of RFC 8032. A
	secret seed signs, and anyone with its public key can check, 1.9ms on an
	M4 and 17ms on a Raspberry Pi 4. `docs/ai_digest/crypto.md`.

*	The loads of the native code that 7.2 had as not ready on a real RISC-V
	or LoongArch are aligned in every call the library makes. Only the
	native code called by hand with an odd offset is not.
	`docs/ai_digest/crypto.md`.

## Fixes

*	A command that does not exist is "Pipe Error !", it hung the terminal.
	The kernel again looks that a `.lisp` file is there before it starts a
	task for it, a look lost on 8 September, in 7.1 and 7.2.

*	The rules of a `.gitignore` in `sync`, a line with a space or a return
	on the end was not matched.

## Not ready

*	What goes over a link is not hidden or signed, the key says who is let
	in.
