# ChrysaLisp 7.4

A draft, what has gone in since the 7.3 tag.

## Sync

*	A waypoint goes round the herd by itself. Each machine's sync service
	offers the waypoint its tree is exactly at to the others, as it starts,
	when a machine is new to it or back, when it has taken one, and when
	`waypoint` notes one; each takes what is newer and offers it on.
	`service/sync/spread.lisp`, [sync.md](../ai_digest/sync.md), "The herd
	by itself".

*	A tree with no `.git` that is already exactly the tree at a waypoint
	takes it, only the waypoint noted, and a push from a machine it names,
	made from a tree at its waypoint, notes it there too.

*	A machine the herd has taken to a newer waypoint makes itself new. Its
	member ends, and `rack.sh`, which keeps it in a loop, does `make
	install` and starts it again; what was there is put back if the
	install fails. Only the member, its own nodes, and not on a tree with a
	`.git`. [rack.md](../ai_digest/rack.md), "A member". As it starts, a
	member does the same if its boot image was made from other source than
	its tree has, `boot_files` beside the image and `(boot-id-tree)`.

*	`waypoint` notes one only when the tree is exactly the commit, by git's
	index, as `git status` first looks, and says what is not. It had said
	there was no commit on every real tree.
