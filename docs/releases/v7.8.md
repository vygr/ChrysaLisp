## Apps

*	The MNIST app is Digits, `apps/science/digits`: it is named for what
	it learns, as the next networks of `lib/nn` will be, and MNIST is the
	data set it learns them from, whose names keep it. Its data folder
	moves with it, so a data set fetched already is not fetched again
	where the tree is moved rather than cloned. Its settings are kept in
	`digits.tre`, the rate, batch and back end chosen under the old name
	are not carried over.
